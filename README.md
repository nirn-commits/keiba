# ダービー牧場物語

配合理論で名馬を生み出す、ブラウザで遊べる競馬経営シミュレーションゲームです。
レースシーンは簡易的にし、**配合・育成・牧場経営**のシミュレーションに重きを置いています。

## 遊び方

ビルドは不要です。`index.html` をブラウザで開くだけで遊べます。

```
# ローカルサーバーで開く場合
python3 -m http.server 8000
# → http://localhost:8000/
```

進行状況は週ごとにブラウザ（localStorage）へ自動保存されます。「牧場経営」タブからJSONでエクスポート・インポートもできます。

## 主なシステム

| 分野 | 内容 |
| --- | --- |
| 時間 | 1年48週（各月4週）。毎週「次の週へ」で進行します。 |
| 生産サイクル | 2月2週〜5月4週が種付けシーズン。仔は翌年2月に誕生し、2歳の1月に入厩、6月にデビューします。 |
| 配合理論 | インブリード（3×4など）、ニックス（父系統×母父系統）、活力補完、因子、爆発力（★評価）、近親配合による虚弱リスク。 |
| 血統 | 8つの親系統と、そこから分岐する子系統。5代血統表でクロスを強調表示します。産駒がGIを3勝した種牡馬は自身の系統を確立します。 |
| 能力 | スピード／スタミナ／パワー／瞬発力／根性／賢さ／健康、距離適性、芝・ダート適性、成長型（早熟・普通・晩成）、脚質。若駒の能力は推定値で表示されます。 |
| 競走 | 新馬・未勝利〜オープン・重賞（GI〜GIII 60競走以上の年間カレンダー）。クラス昇級制。調教強度、疲労・調子・故障、放牧。 |
| ローテーション | 馬ごとに1年半先までの重賞や自己条件戦を予定に組めます。出走方針は「自動（ローテ優先）」「ローテのみ」「手動」から選べます。 |
| レース | 能力と展開（ペース・脚質）から結果を計算し、canvasで簡易アニメーション観戦ができます。 |
| 経営 | 賞金、預託料、種付料、馬の売買（繁殖牝馬セール・1歳馬セール）、施設拡張（繁殖厩舎・育成牧場・放牧地・契約厩舎）。 |
| 引退 | 牝馬は繁殖入り、重賞勝ちや高能力の牡馬は種牡馬入り。活躍馬は因子を獲得し、自家種牡馬は毎年の種付料収入を生みます。 |

## ファイル構成

```
index.html
css/style.css
js/util.js      汎用関数
js/data.js      系統・ニックス・重賞カレンダー・施設などの定義
js/genetics.js  能力計算・血統・配合評価・仔の生成
js/world.js     NPC種牡馬/繁殖牝馬の世界生成と年次更新、市場
js/race.js      レース番組・出走判定・能力値・レースシミュレーション
js/game.js      週送り・経営・売買・セーブ
js/viewer.js    レース観戦アニメーション
js/ui.js        画面描画と操作
```
